# AoE IV Atlas — 文明と戦術の手帖

日本語の静的な文明・戦術ガイドです。ビルドや外部サービス、APIキーは不要です。公式一覧で確認した23文明を収録しています。公開作業はまだ行っていません。

## 開く

`dist/index.html` をブラウザで開けば使えます。Node.js 18以上がある場合は、このフォルダで `npm start` を実行して http://127.0.0.1:4173 を開いてください。依存パッケージのインストールは不要です。

## 機能

- 文明名・英語名・ユニット・研究／システム・戦術・内政方針を全文検索。空白区切りはAND検索で、かな／カナ・英字大小文字・全半角を正規化します。
- パワースパイクの時代、基本／追加文明で絞り込み。
- 文明別の特徴、代表ユニット、研究／システムを表示。
- 文明ごとに2つの戦術を選択。時間帯と暗黒内政の配分方針が連動します。
- URLの `#` に選択と検索を保存。再読み込みやURL共有で再現できます。
- スマートフォン表示、キーボード操作、検索ショートカット `/` に対応。

## GitHub Pagesで公開する

1. GitHubで空のリポジトリを作成します。例：`aoe4-atlas`。
2. このフォルダの**中身**をリポジトリ直下へ追加します。`dist`、`package.json`、隠しフォルダの `.github` も含めてください。ZIPをそのまま置くのではなく展開したファイルを登録します。
3. リポジトリの **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選びます。
4. **Actions → Publish AoE IV Atlas → Run workflow** から手動で実行します。既定ブランチにワークフローが必要です。
5. 成功すると Pages の設定画面と実行結果に公開URLが表示されます。通常は `https://ユーザー名.github.io/aoe4-atlas/` です。

更新時も同じワークフローを手動実行します。ファイルをpushしただけでは公開しない設定です。アセットは相対パスのため、リポジトリ名が変わっても動きます。

Gitを使う場合は、空のGitHubリポジトリの案内に従ってこのフォルダを登録してください。こちらではリポジトリ作成、push、公開は行っていません。

[GitHub公式：Pagesの公開元を設定する](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## 内容を編集する

| ファイル | 内容 |
| --- | --- |
| `dist/data.js` | 文明、出典、戦術、内政案のデータ |
| `dist/app.js` | 検索・絞り込み・詳細表示 |
| `dist/styles.css` | 色、レイアウト、スマートフォン表示 |
| `dist/index.html` | タイトル、検索欄、ページ全体 |

`data.js` の `rows` に各文明が1行ずつあります。フィールドの順序は直前のコメントに記載しています。ユニット／システムは `名前~説明|名前~説明` で記述します。表示時はHTMLをエスケープします。戦術の共通手順は `ATLAS_PLANS`、文明ごとの差は `opening`（暗黒固有方針）と `condition`（攻め時の条件）です。

現段階の時間帯は文明固有の実測値ではなく、戦術タイプごとの編集上の目安です。検証済みビルドを追加する場合は文明×戦術で個別の手順・人数・計測時間・パッチ番号・検証動画やリプレイURLを持つ形式に拡張してください。未検証表示を消す前に、その条件で実戦確認を行ってください。

## 情報の範囲

- 資料確認日：2026-09-20。
- 文明の特徴と代表ユニット／研究・システムは、各文明の公式紹介を短く要約しています。全ユニット・全研究のデータベースではありません。
- 公式紹介ページにも古い仕様が残る場合があるため、最新パッチ適合は未検証と表示しています。数値・研究費・正確な日本語ゲーム内名称を保証するものではありません。
- 戦術と暗黒内政は、標準資源・1v1陸マップを想定した練習用の配分方針です。農民人数を固定した再現検証済みビルドではありません。海・ハイブリッド・チーム戦には別の調整が必要です。
- 時間帯は勝率や強さの順位ではありません。ジャンヌの経験値、軍量、研究完了など条件を一緒に見てください。
- 画像やゲームアセットの転載はしていません。Age of Empires IV は Microsoft グループの商標で、本サイトは非公式です。

[公式文明一覧](https://www.ageofempires.com/civilizations/)から23文明それぞれの紹介へアクセスできます。各詳細画面にも出典リンクがあります。

## 確認

`npm run check` でJavaScript構文、データの必須項目、戦術の参照、ローカルのアセット参照を確認します。公開ワークフローでも同じ検査を実行します。ゲーム内容の実戦検証や公開環境へのデプロイ検証は含みません。

WebMCP対応ブラウザでは検索用の `search_civilizations` を登録します。非対応環境では通常の検索UIが動作します。
